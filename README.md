# neologdn-java

[![](https://jitpack.io/v/ikegami-yukino/neologdn-java.svg)](https://jitpack.io/#ikegami-yukino/neologdn-java)

`neologdn` is a Japanese text normalizer for [mecab-neologd](https://github.com/neologd/neologd).

The normalization of `neologdn` is based on the neologd's rules: [https://github.com/neologd/mecab-ipadic-neologd/wiki/Regexp.ja](https://github.com/neologd/mecab-ipadic-neologd/wiki/Regexp.ja)

Contributions are welcome!

## Usage

```java
import io.github.ikegamiyukino.neologdn.NeologdNormalizer;


NeologdNormalizer normalizer = new NeologdNormalizer();
String text = "　　　ＰＲＭＬ　　副　読　本　　　";
normalizer.normalize(text);
// => "PRML副読本"
```

### Python neologdn compatibility

The normalizer targets [Python neologdn 0.5.6](https://github.com/ikegami-yukino/neologdn)
for valid Unicode text. Malformed UTF-16 strings containing unpaired surrogates are
outside this compatibility guarantee.
The existing `normalize(String)` method uses the same defaults: repetition shortening
disabled, Japanese space removal enabled, maximum repeated substring length 8, and
tilde removal.

```java
normalizer.normalize("無駄無駄無駄無駄ァ", 1);
// => "無駄ァ"
normalizer.normalize("巴 マミ", false);
// => "巴 マミ"
normalizer.normalize("1995〜2001年", "normalize");
// => "1995~2001年"
normalizer.normalize("1995~2001年", "normalize_zenkaku");
// => "1995〜2001年"

// Full signature, in the same argument order as Python:
// normalize(text, repeat, removeSpace, maxRepeatSubstringLength, tilde)
normalizer.normalize("オラオラオラオラーッ", 2, true, 8, "remove");
// => "オラオラーッ"

// Shorten repetitions without normalizing the text:
normalizer.shortenRepeat("無駄無駄無駄無駄ァ", 1);
// => "無駄ァ"
normalizer.shortenRepeat("隣の客はよく柿食う客だ、隣の客はよく柿食う客だ、隣の客はよく柿食う客だ、言えた！", 1, 0);
// => "隣の客はよく柿食う客だ、言えた！"
```

| Java argument | Python argument | Default | Behavior |
| --- | --- | --- | --- |
| `repeat` | `repeat` | `0` | Maximum repetitions to retain; `0` disables shortening in `normalize` |
| `removeSpace` | `remove_space` | `true` | Remove spaces around Japanese characters |
| `maxRepeatSubstringLength` | `max_repeat_substr_length` | `8` | Maximum repeated substring length; `0` means unlimited |
| `tilde` | `tilde` | `"remove"` | `"remove"`, `"ignore"`, `"normalize"` (ASCII `~`), or `"normalize_zenkaku"` (`〜`) |

Overloads also accept `(text, repeat, removeSpace)` and
`(text, repeat, removeSpace, maxRepeatSubstringLength)` with remaining defaults.
`shortenRepeat(text, repeatThreshold)` defaults to a maximum substring length of 8;
its three-argument form accepts a custom maximum. Lengths count Unicode code points,
so supplementary characters such as emoji are not split.

Compatibility details:

- Fullwidth spaces become ASCII spaces even with `removeSpace=false`. Like Python,
  one trailing ASCII space is always removed (`"abc   "` becomes `"abc  "` when space
  removal is disabled).
- Shortening follows Python's scan order and exclusive search bound. For example,
  `shortenRepeat("aaa", 1)` stays `"aaa"`, while `shortenRepeat("aaaa", 1)` becomes `"a"`.
- A zero threshold passed directly to `shortenRepeat` removes scanned substrings,
  matching Python; use `normalize(..., 0)` to disable shortening instead.
- Unknown tilde modes remove tildes, matching Python. Negative repetition parameters
  are rejected with `IllegalArgumentException` rather than reproducing Python's
  negative-index behavior. Input text must not be `null`.
- Normalization removes one leading U+FEFF byte order mark after character and space
  processing, matching Python's UTF-32 decoding. `shortenRepeat` alone preserves it.

Compared with earlier Java releases, default output now matches Python for voiced
and semi-voiced marks (including `う゛ほﾟ` → `ゔぽ`), standalone marks (`゛` → `ﾞ`),
curly quotation marks, the yen sign, trailing spaces, and spaces before hyphens,
long-vowel marks, and tildes. Python's mapping is selective: characters such as
`＂`, `＇`, `＼`, and `｀` remain unchanged. Existing method signatures remain available.

### Testing

Run `mvn test`. The suite includes 710 stored input/output cases generated by the
Python 0.5.6 extension, so ordinary Java tests do not require Python.

To regenerate the fixtures, use a Python environment with `neologdn==0.5.6` installed:

```sh
python src/test/python/generate_compatibility_fixtures.py
```

For a broader comparison covering every non-surrogate BMP code point, supplementary
characters, and deterministic random inputs:

```sh
python src/test/python/generate_compatibility_fixtures.py --extended --output /tmp/neologdn-parity.tsv
mvn test -Dneologdn.compatibilityFixture=/tmp/neologdn-parity.tsv
```

## Installation

`neologdn` can be added to your project through either JitPack or GitHub Packages.

### JitPack

[JitPack Link](https://jitpack.io/#ikegami-yukino/neologdn-java/)

#### maven

Add the following tags to your `pom.xml`:

```xml
<repositories>
    <repository>
        <id>jitpack.io</id>
        <url>https://jitpack.io</url>
    </repository>
</repositories>

<dependency>
    <groupId>com.github.ikegami-yukino</groupId>
    <artifactId>neologdn-java</artifactId>
    <version>v0.1.0</version>
</dependency>
```

#### gradle

Add it in your root `settings.gradle` at the end of repositories:

```groovy
	dependencyResolutionManagement {
		repositoriesMode.set(RepositoriesMode.FAIL_ON_PROJECT_REPOS)
		repositories {
			mavenCentral()
			maven { url 'https://jitpack.io' }
		}
	}
```

Add the dependency

```groovy
	dependencies {
	        implementation 'com.github.ikegami-yukino:neologdn-java:v0.1.0'
	}
```

### GitHub Packages

#### maven

Add the following tags to your `pom.xml`:

```xml
<project>
    <dependencies>
        <dependency>
            <groupId>com.github.ikegami-yukino</groupId>
            <artifactId>neologdn-java</artifactId>
            <version>0.1.0</version>
        </dependency>
    </dependencies>

    <repositories>
        <repository>
            <id>github</id>
            <name>GitHub Packages</name>
            <url>https://maven.pkg.github.com/ikegami-yukino/neologdn-java</url>
        </repository>
    </repositories>
</project>
```

and maybe also edit your `~/.m2/settings.xml`.

```xml
<settings>
    <servers>
        <server>
            <id>github</id>
            <username>Your GitHub name</username>
            <password>Your Personal Access Token</password>
        </server>
    </servers>
</settings>
```

#### gradle

Add it in your root `settings.gradle` at the end of repositories:

```groovy
repositories {
    mavenCentral()
    maven {
        name = "GitHubPackages"
        url = uri("https://maven.pkg.github.com/ikegami-yukino/neologdn-java")
        credentials {
            username = project.findProperty("gpr.user") ?: System.getenv("GITHUB_ACTOR")
            password = project.findProperty("gpr.key") ?: System.getenv("GITHUB_TOKEN")
        }
    }
}

dependencies {
    implementation 'groupId:artifactId:version'
}
```

Add GitHub info to `~/.gradle/gradle.properties`:

```groovy
gpr.user=Your GitHub account name
gpr.key=Your Personal Access Token (classic)
```
